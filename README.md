# Stealthify
Developed a versatile steganography tool enabling secure text concealment within images. 
Leveraging steganography and cryptography techniques, the tool facilitates encoding, decoding, encryption, and decryption of hidden messages. 
Users can seamlessly encode secret messages, encrypt them for added security, and decode and decrypt them when needed.

# Tech Stack used:
* Python
* Streamlit
* Steganography
* Cryptography
